# LibAdmin

Windows 上的本地书库管理程序。它扫描文件夹里的 PDF、EPUB、DJVU、MOBI、AZW3、FB2，按作者和类别整理成条目，用磁贴显示封面。同一本书的不同版本、译本、分卷和配套资料可以合并成一个条目。

程序只建立索引和封面缓存。**不会复制、移动或修改书本原文件。** 用系统默认阅读器打开文件。

## 书库怎么组织

先选择一个根目录。根目录下的每个一级文件夹是一个独立书库，例如：

```
书库根目录/
  Mathematics and Physics/
    分析/
      Stein - Fourier Analysis.pdf
  计算机书籍/
```

在程序里用左上角的下拉框切换书库。

索引默认写在该书库的 `.libadmin` 目录里。如果书库所在位置不能写入，索引会改存到软件旁的 `library_data`。封面是根据文件生成的 JPEG，也只存在索引目录中。

## 使用

- 单击磁贴选中条目，右侧栏显示条目信息和其中的文件。
- 双击磁贴打开条目。双击右侧文件用阅读器打开。
- 拖动左右分隔线可调整边栏宽度。右侧栏可以收回。
- 条目可以新建、编辑、合并、拆分。从索引里移除条目不会删除磁盘上的文件，可在「已移除」中恢复。
- 类别是一棵可编辑的树。选中某个类别时，只显示直接属于该类别的条目，不含其子类别。
- 条目里的文件可以改显示名称、作者、语言和角色（主本、其他版本、译本、分卷、章节、配套资料）。这些信息只写在索引里。有译本时，磁贴左上角会显示「译本」。
- 右上角 **⋯ → 重新生成全部封面** 会重做当前书库的封面缓存，仍然不改书本文件。

## 从源码运行

需要 Rust（含 MSVC）、以及系统里的 WebView2（Windows 10/11 一般已自带）。

```bat
run-app.bat
```

开发时封面工具从仓库里的 `tools` 目录读取（pdfium 与 DjVuLibre）。

## 打包便携版

```bat
pack-portable.bat
```

生成 `dist\LibAdmin.exe`。这一个文件即可拷走使用。第一次运行时，封面工具会解压到 `%LOCALAPPDATA%\LibAdmin\runtime\`。`settings.json` 写在 exe 旁边。上级目录里即使有别的 `tools` 文件夹，也不会被当成这个程序的目录。
